# 🏛️ Governança do Projeto

Este documento define as regras de governança do repositório **Banco de Dados NoSQL – 4º Semestre**.

---

## 👥 Mantenedores
O projeto é mantido por:
- **Anderson de Matos Guimarães** (coordenador do repositório)

---

## 📌 Responsabilidades
- **Mantenedores**:
  - Revisar e aprovar *pull requests* (PRs)
  - Garantir que o código siga os padrões definidos
  - Publicar *tags* e *releases* oficiais
  - Zelar pela aplicação do [Código de Conduta](CODE_OF_CONDUCT.md)

- **Colaboradores**:
  - Contribuir com código, documentação e sugestões
  - Abrir *issues* para reportar bugs ou propor melhorias
  - Seguir as orientações do [CONTRIBUTING.md](CONTRIBUTING.md)

---

## 🛠️ Processo de decisão
- Mudanças simples (documentação, ajustes menores) → aprovadas por **1 mantenedor**.  
- Mudanças significativas (novas funcionalidades, impacto no projeto) → exigem aprovação de **pelo mantenedor**.  
- Em caso de divergência, a decisão final será do **coordenador (Anderson)**.

---

## 🔄 Ciclo de desenvolvimento
1. As tarefas são organizadas em **Issues**.  
2. Cada tarefa é associada a uma **branch** de desenvolvimento.  
3. Contribuições chegam via **Pull Request**.  
4. O código aprovado é integrado na branch `main`.  
5. Versões estáveis são marcadas com **tags** e documentadas nas **Releases**.  

---

## 📜 Transparência
- Todas as discussões relevantes devem ocorrer via Issues ou PRs.  
- Não serão aceitas decisões tomadas apenas em canais privados.  

---

## ⚖️ Alterações na governança
Mudanças neste documento podem ser propostas via Pull Request e devem ser aprovadas por **todos os mantenedores**.
