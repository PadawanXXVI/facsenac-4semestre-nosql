# 🔒 Política de Segurança

## Versões suportadas
Atualmente este repositório está em desenvolvimento acadêmico e **não possui versões mantidas para produção**.  
As versões estáveis (entregas finais) serão indicadas nas [Releases](../../releases).

## Relato de vulnerabilidades
Se você encontrar alguma vulnerabilidade ou problema de segurança, siga as orientações:

1. **Não abra uma issue pública**.  
2. Envie um e-mail para:  
   - Anderson de Matos Guimarães: [anderson.m.guimaraes@icloud.com](mailto:anderson.m.guimaraes@icloud.com)  
   - Renan Ost: *(incluir contato, se disponível)*  
3. Forneça informações detalhadas:
   - Descrição do problema
   - Passos para reproduzir
   - Possível impacto
   - Sugestões de correção, se houver

## Boas práticas no repositório
- Nunca publicar senhas, tokens ou credenciais em commits.  
- Usar arquivos `.env` (ignorados pelo `.gitignore`) para dados sensíveis.  
- Testar os scripts antes de abrir pull requests.  

## Reconhecimento
Problemas de segurança reportados de forma responsável serão investigados e corrigidos com prioridade.  
Contribuidores que ajudarem podem ser reconhecidos nas notas de versão.
