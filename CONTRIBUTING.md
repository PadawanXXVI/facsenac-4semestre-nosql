# 🤝 Guia de Contribuição

Obrigado por considerar contribuir com este projeto acadêmico de **Banco de Dados NoSQL** 🎓  

## Como contribuir
1. **Faça um fork** do repositório.  
2. **Crie uma branch** para a sua contribuição:  
   ```bash
   git checkout -b feature/nome-da-sua-feature
   ```
3. **Realize os commits** seguindo a convenção:  
   - `feat:` para novas funcionalidades  
   - `fix:` para correções  
   - `docs:` para documentação (README, LICENSE, etc.)  
   - `chore:` para tarefas de manutenção  
4. **Envie um Pull Request** (PR) descrevendo claramente as mudanças.  

## Diretrizes
- Código limpo, comentado e funcional.  
- Não subir arquivos sensíveis (.env, credenciais).  
- Atualizar a documentação (README, CHANGELOG) quando necessário.  
- Testar antes de abrir um PR.  

## Fluxo de revisão
- Todos os PRs serão revisados por **Anderson de Matos Guimarães** e **Renan Ost**.  
- Feedbacks serão dados via comentários no PR.  
- Alterações solicitadas devem ser resolvidas antes da aprovação.  

## Comunicação
- Use **Issues** para reportar bugs ou sugerir melhorias.  
- Evite discussões fora do GitHub para manter a transparência.
