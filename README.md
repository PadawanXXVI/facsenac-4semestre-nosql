## 📖 Sobre o repositório
Repositório dedicado à disciplina **Banco de Dados NoSQL**, do **4º semestre de Ciência de Dados** na **Faculdade de Tecnologia e Inovação Senac-DF**, ministrada pelo professor **Edgar Amoroso**.  

O conteúdo está organizado em **aulas práticas** contendo códigos, atividades e exercícios relacionados a bancos de dados NoSQL, com foco inicial em **MongoDB**, **Cassandra** e outros SGBDs não relacionais.
